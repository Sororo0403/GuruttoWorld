# ゲーム制作の作業範囲

- このフォルダーが「ぐるっとワールド」のゲームプロジェクトです。
- シーン・Prefab・素材・ゲーム処理は、このプロジェクトの `Assets` と `Shaders` で制作します。
- ビルドは `GuruttoWorld.slnx` の Debug／Development／Release、x64を使用します。
- エディター・Engine・SceneRuntime・共通ビルド処理の修正は、エディター修正用チャットで行います。
- エディターの不具合は再現手順と必要な素材のパスを整理し、ユーザーに報告します。
- 起動シーンと既存の制作データは、依頼なしに生成スクリプトで上書きしません。
- 実装・修正の完了報告には、一行のコミットメッセージを添えます。
