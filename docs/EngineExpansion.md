# エンジン機能拡張

2026-10-07: Unityのようにゲームを制作できる環境を目指し、以下を実装する。
検証が通った機能単位でコミットし、未完了項目は完了扱いにしない。

- [x] ゲーム処理API: 検索、Component取得、生成・複製・削除、イベント
- [x] 物理: 動的剛体、Collider、Trigger、衝突イベント、Raycast、斜面・移動床
- [x] Prefab: プロパティ単位の上書き、適用・復元、入れ子、Variant
- [x] 描画: PBR、法線マップ、Point/Spot Light、ポストエフェクト
- [ ] アニメーション: GPUスキニング、Blend Tree、イベント、IK、ルートモーション
- [ ] アセット・性能: 画像圧縮・Mip設定、CPUスコープ・GPUパス別計測

描画: PBR（GGX・金属度・sRGB変換）と接線空間の法線マップ、Material編集・保存、Point/Spot Light（32灯、距離・角度減衰、親子とScript追従）、線形FP16 HDR、露出・Reinhard/ACES近似・ブルーム、比較シーンを追加。UIはポストエフェクトの後で描画する。

アニメーション: GPUスキニングを追加。頂点・インデックスは不変で複製キャラクター間でも共有し、フレームごとのボーン行列だけを更新する。影も同じ姿勢で描画する。ボーンごとの領域から保守的なBoundsを更新し、Editorの選択判定は必要時に現在の三角形を計算する。1D・2D・Direct・入れ子のBlend TreeとInspector編集・比較シーンを追加。時刻・引数・重み付きのアニメーションイベントをScriptへ接続し、全個体の姿勢・イベントをまとめて反映する更新を追加。ルートモーションは引き続き実装する。

IK: 二関節の解析解と目標・曲げ方向・重み、Animatorの制約保存・適用、Inspector編集、World座標目標、Scriptの個体別目標上書き・解除、重みの比較シーンを追加。App／Editorの再生と先端追従、CPU変形に対するGPU画像、失敗時の全個体・Script状態保持を検証する。Skeleton内部のチェーン・祖先は正の一様Scaleを必要とする。ルートモーションは引き続き実装する。

既存のシーン形式・再生停止時の編集データ復元・失敗時のデータ保持を維持する。
新機能はAppとEditorの再生双方へ接続し、APIだけの追加で終わらせない。
