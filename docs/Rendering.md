# 描画・照明

Windows／DirectX 12のEditorとAppは同じ描画経路を使います。設定はシーンまたはMaterialに保存されます。

## LODと描画の集約

MeshRendererのInspectorでLODモデルと距離を追加すると、カメラからオブジェクト原点までのワールド距離でモデルが切り替わります。距離は昇順で最大8段階です。元モデルのMaterialとスロット割り当てを引き継ぐので、LODモデルも対応するスロット構成にします。モデル読み込みに失敗した編集は現在のシーンを保持します。Animator付きモデルは静的LODの対象外です。

GPUインスタンシングを有効にした静的モデルは、同じモデル・Material・スロット・面の巻き順を持つ個体を最大257個ずつまとめます。不透明パスの`DrawIndexedInstanced`で各個体の行列を読みます。透明パスは距離順の個別描画を保ちます。Profilerのdraw数は実際のバッチ数、三角形数は全個体分です。

GPU遮蔽カリングは、そのフレームの深度に境界箱を描いてbinary occlusion queryを実行します。結果をGPUバッファーへ解決し、後続メッシュをpredicationで条件付き描画します。過去フレームの結果は使用しません。境界箱がカメラ近傍を横切る場合は保守的に描画します。個別の遮蔽判定を有効にした物体はインスタンシングから外れます。描画命令の発行数はProfilerへ計上されますが、遮蔽された物体のGPU処理は省略されます。

## 局所光源の影

PointLightとSpotLightのInspectorでリアルタイム影を有効にできます。点光源は六面、スポットライトは円錐の透視投影を使い、512pxの深度アトラスへ描画します。各光源の保存値と親を含むワールド変換が反映されます。影は3×3の比較サンプルで平滑化します。

アトラスは32面です。点光源は6面、スポットライトは1面を消費します。ヒエラルキー順に割り当て、容量を超えた光源は影なしで照明を続けます。透明なメッシュは影を落としません。

## IBLとライトマップ

Materialの環境照明パノラマに正距円筒画像を指定すると、画像から環境照明を評価します。PBR材質では半球方向の拡散照明、反射方向・粗さに応じたmipの鏡面照明、環境BRDFの近似を使います。環境照明の強度をMaterialに保存できます。読み込んだ画像のmipを使用する簡易IBLなので、GGXで事前積分した反射プローブのベイクは行いません。

「照明ベイク」パネルでは、選択した静的MeshRendererの元UV上へ、現在の環境光・平行光源・点光源・スポットライトをCPUでベイクします。光源に向かうレイをシーンの実三角形へ当てて遮蔽も保存します。解像度は16～512、元UVは0～1で重ならないように作成してください。自動UV展開は行いません。

生成画像と独立したMaterialは`Assets/Textures/Baked`と`Assets/Materials/Baked`へ保存します。既存Materialの見た目とスロットを引き継いだ割り当てはシーンのUndo対象です。元のMaterialを上書きしません。画像自体はアセットとして残ります。ライトマップを使う材質はベイク済み照度で直接照明を置き換え、IBLは追加できます。光源や形状を変えたら再ベイクしてください。保存形式はsRGBのLDR BMPで、1を超える照度は切り詰めます。

## 自動露出と色調整

シーン設定のポストエフェクトで自動露出を有効にできます。GPUが画面全体の16×16サンプルから対数平均輝度を計算し、中間灰色へ合わせる露出をEV上下限へ制限します。手動露出は補正として追加されます。毎フレーム即座に測光し、時間的な明暗順応は行いません。

カラーフィルター、コントラスト、彩度は線形HDR上でトーンマッピング前に適用します。シーンUIは既存どおりポストエフェクト後に描画されます。保存・Inspector・Undoは他のシーン設定と共通です。
