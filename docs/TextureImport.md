# 画像インポート

画像アセットのInspectorでMip生成、最大サイズ、BC3圧縮、sRGBでのMip計算を編集し、「設定を保存・再インポート」で適用する。設定は既存のアセットIDを維持して.metaへ保存する。以前の.metaは圧縮なし・Mipなし・最大16384・線形フィルターとして読み込める。

Texture2DはWICで読み込んだRGBA画像を、縦横比を保ちながら最大サイズ以下へ縮小する。Mipは各寸法を半分にし、1×1まで生成する。奇数寸法の末端画素も平均に含める。sRGBの設定はRGBを線形光へ変換して平均し、sRGBへ戻す。Alphaは線形に平均する。法線やデータ画像には線形の設定を使用する。

BC3は4×4ブロックごとの色とAlphaを圧縮し、GPUのBC3_UNORMとして転送する。色の範囲から端点を選ぶ基本的な圧縮であり、画像によって色の誤差が生じる。最上位寸法が4の倍数でない画像は、寸法を維持してRGBA8へ戻す。小さいMipは部分ブロックを端の画素で埋める。ブロック形式の条件は[Microsoftの仕様](https://learn.microsoft.com/en-us/windows/win32/direct3d10/d3d10-graphics-programming-guide-resources-block-compression)を参照。

全MipをD3D12のサブリソースとして転送し、SRVへ全レベルを公開する。メッシュ・Material・スプライト・プレビューに同じ読み込み設定を適用する。メッシュとスプライトのキャッシュは画像と.metaの変更を検出し、新しいリソースへ切り替える。既存の描画が共有している古いリソースは参照がなくなるまで保持する。

WP1_TEXTURE_IMPORT_ONLY=1で奇数寸法、sRGBの平均、最大サイズ、BC3のMip末端、GPU描画の画素一致、非整列画像のRGBA復帰、不正設定の保持、設定保存後のキャッシュ更新を検証する。
