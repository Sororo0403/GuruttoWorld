# 市場の分岐と、歩いて体験する開放の順序

2026-10-16。前版で弱かった「分岐前の比較」「囲いが開く過程を必ず体験すること」を、StreetJourney の構造と静的装飾で修正する。地図、マーカー、説明文字は使用しない。タイトル、操作、戦闘、近距離カメラの処理を維持する。

## 市場の選択を、曲がる前に見せる

中央の市場棟の正面をz=33からz=38へ下げ、幅も7mから4mへ変更。屋根付きの共通前庭を設け、店のカウンターは東端へ移す。西側にも実際に通れる床を追加し、護岸越しの隙間を通路として見せない。

分岐の判断位置は(7,30)。この同じ位置から、荷捌き通りの床(1,39)と公共通りの床(14,39)の両方を見せる。装飾や入口の上端だけではなく、人物が入れる高さの通路を確認する。両方とも庭へ出て、周回して戻れる。

## 日よけの違いを、寄り道の比較から主動線の体験へ

市場の大屋根はx=-6〜20、z=27〜44.5を覆う。客の通路と荷捌き通りが同じ市場の雨よけを共有する構造。既存のカメラが屋根の下で追従できるよう、屋根中心高さを6.1mとする。

その先のz=44.5〜57は、同じ市場から続く休憩庭の格子棚。柱の割付と高さを引き継ぎ、上を覆う面だけが板屋根から隙間のある木の格子へ変わる。座席・花壇は通路の外へ寄せ、街の休憩場所として機能する。両方の市場通りから階段へ向かう通常の地上動線はこの庭を通る。

階段から屋上へは天井を設けず、その先の屋上庭園・時計台の展望所も空に開く。これにより「覆われる→隙間から空が見える→上が全面開く」を同じ順序で歩いて体験できる。三種類の装飾を別の寄り道に置いただけの比較を解消する。

修辞の漸層を参考にした、開放の度合いの段階的な配列。文学上の漸層法を厳密に空間へ再現した、あるいは認知的効果を実証したとの説明はしない。

## その他の修正

- 入口のカフェ席を既存の庇の下へ移し、席と庇が離れていた配置を修正。
- 歯車を人物の手が届く高さへ下げ、機構の接続を維持。入力方法そのものが形だけで必ず伝わるとは扱わない。
- 歯車の中心を高さ1.5m、東側の設備位置へ移し、軸・台座・実物に対応する衝突判定を追加。下端が床へ入り込まず、操作位置の人物とも重ならないことを検査。
- 市場の物販カウンターと荷物、庭の休憩席を用途に沿ってまとめ、分岐の見通しと歩行幅を空ける。
- 直交する梁の上下を分け、重複面のちらつきを防ぐ。共通屋根・柱・格子は既存の静的バッチへ焼き込み、照明や動的演出は増やさない。

## 確認方法

同じ判断位置から両通路の画面内への投影と物理的遮蔽をネイティブ実行で検査する。実際の焼き込みポリゴンへの鉛直サンプルで、市場はほぼ全面、庭は部分的、屋上はゼロという上空の被覆率を検査する。左右の市場通りと庭の複数の歩行位置を対象にし、技法名やメタデータだけでは検査に通らないようにする。

描画付きの通し操作と判断位置・屋根の下・格子棚の下・屋上の静止視点も確認する。通行可能性・表示の確認と、初見プレイヤーの理解度は区別する。
