# 資料を基にした街区の全面再構成

次の修正版の市場と屋根の構造は [StreetWalkableSequence.md](StreetWalkableSequence.md) を参照。以下は全面再構成時点の記録。

2026-10-16。ユーザー提供の `deep-research-report.md` を設計の参考として、StreetJourney の地形、建物配置、周回路、到達先を置き換えた。既存の移動、戦闘、歯車、落下復帰、タイトル、近距離カメラのコードは変更しない。

## 資料から採用したこと

資料の「注意・記憶・空間認知」を、装飾の量ではなく、場所を区別できる用途、進む前に見える接続、戻って同じ場所と分かる構造として実装する。資料の引用文献は書誌情報やリンクが不足しており、個々の心理学的効果を実証済みとは扱わない。地図、UI、発光経路、音声案内の提案は、このプロジェクトの条件に含めない。

| 場所 | 構造と用途 | 修辞から借りた構成 |
|---|---|---|
| 入口 | 広場の中に独立したカフェ。左右を回って同じ岸壁へ出る | 正面の店と両側の開口の対比。単に奥へ進む形を避ける |
| 水路 | 連続する二つの護岸と、対岸に広がる市場のテラス | 地上と屋上で、対岸・切れた欄干・着地点という関係を反復 |
| 市場 | 市場棟の東に高い石のアーケード、西に低い木の荷捌き庇。両方とも庭へ接続 | 同じ目的地に至る二つの用途を対比。柱の反復は実際の構造材 |
| 庭 | 市場の背後の休憩所。植栽を避けると階段と駆動機構が見える | カフェの庇、庭の格子棚、屋上の空へと囲いが段階的に開く |
| 屋上 | 横方向に二棟を渡り、花壇の前後を回れる空中庭園 | 地上で学んだ渡り方を高さが変わった場所で再利用 |
| 終点 | 時計台に隣接した、幅8m・奥行7mの入れる展望所 | 時計は一基だけ。特徴を複製せず、到達先を特別なものにする |

技法名をゲームへ表示せず、文学上の定義をそのまま空間へ適用したとも主張しない。用途として成立する建築の配置に、対比・反復・段階的変化を応用したもの。

## 再生成と確認

`scripts/AuthorStreetJourney.py` が `scripts/StreetJourneyTown.py` の地形と配置を焼き込み、START の接続先を維持する。Route.json は検証専用で、通常プレイ中に描画・読み込みしない。主経路だけでなく入口の反対側、市場の裏通り、屋上の周回、ジャンプ失敗時の着地、チェックポイント復帰もネイティブ検証の対象とする。

静的検証では、参照の整合性、UI禁止、床の同一高さの重複、対岸の開口、階段の接続、家具の接地、CC0素材のハッシュ、描画量を検査する。通過可能性とカメラの検査は自動操作であり、初心者が迷わないことを証明するユーザーテストではない。初見プレイヤーの立ち止まり、引き返し、誤進入は別途観察が必要。

## 今回の確認結果

- 配布版: `Games/GuruttoWorld/generated/builds/Release-20261016000000000000000000000034/App.exe`。以前の配布版は保存。
- タイトルの START から終点までの描画付き検証: 2,362フレーム、158枚の連続キャプチャ。別途5地点の静止視点を確認。
- 更新した配布版の地形を読み込む移動検証: 5,200フレーム。入口の反対側、市場の表裏、歯車とシャッター、落下復帰、12段の階段、屋上ジャンプの往復と別位置、周回、展望所、Escでのタイトル復帰を通過。
- カメラは58度固定、検証中の左右角の幅は約0.310rad。既存の角速度制限・遮蔽回避を維持。
- Python検証20件成功。静的描画31バッチ・124,840ポリゴン。前の版の34バッチから減少し、ポリゴン数は約3,300増加。
- シェーダー準備、パッケージ検査、876ファイルの配布ハッシュ、818ファイルの元アセット・シェーダーとの一致、5ファイルのコンパイル元ハッシュを確認。
